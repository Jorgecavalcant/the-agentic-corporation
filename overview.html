Padrões de comunicação

🎯 Padrão Advisor

  • Agentes eficientes consultam conselheiros
  • Decisões de alta complexidade → Opus
  • Resultados retornam ao agente base
  • Evita desperdício de tokens

📚 RAG-First

  • Base de conhecimento local consultada primeiro
  • Inferências apenas quando necessário
  • Documentos em docs/
  • Tarefas em tasks/ e checklists/

🏷️ White-Label

  • ${COMPANY_NAME} como placeholder
  • ${CEO_NAME} configurável
  • Zero dados hardcoded
  • Credenciais apenas em .env

🗜️ TOKEN-OPTIMIZER

  • Compressão semântica 70% de retenção
  • Script: _jc-core/utils/optimizer.py
  • Protocolo em docs/COMPRESS_PROTOCOL.md
  • Refactoring em lote disponível

📁 Estrutura de Arquivos

  • departamentos/ — 9 departamentos com agentes
  • _jc-core/ — templates, utils, best-practices
  • docs/ — blueprint, organograma, spec
  • installer/ — scripts de instalação
  • .env — configuração segura (gitignored)

🏗️ Hierarquia de Agentes

  • Tier 0 — C-Level (CEO, CTO, CMO…)
  • Tier 1 — Gestão / Orquestradores
  • Tier 2 — Especialistas / Operacional
  • Escalação automática entre tiers
  • YAML frontmatter por agente

🔌 Conectores & Integrações

🛡️ Segurança & Compliance

  • VPS_HOST — acesso SSH ao servidor

  • CEO_NAME — nome do executivo

  • Credenciais de APIs externas
